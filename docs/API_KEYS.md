# API Keys and Environment Variables

CareOps is designed to run gracefully **without paid API keys** by using a deterministic mock mode for Hackathon demonstrations.

## `NEXT_PUBLIC_USE_MOCK_CORAL=true`
By default, this is set to `true`. This tells the application to use the local `careops.db` SQLite database (generated by `npm run seed`) as the source of truth, completely bypassing any network requests to a real Coral MCP server.

## Optional Keys (Real Mode)
If you want to connect CareOps to a live Coral MCP server or use LLMs for text generation instead of deterministic logic, you will need to set up the following keys in your `.env.local` file. **Never commit `.env.local` to version control.**

| Key | Description | How to get |
|---|---|---|
| `CORAL_MCP_SERVER_URL` | The URL of your running Coral MCP bridge. | Required if `NEXT_PUBLIC_USE_MOCK_CORAL=false`. |
| `CORAL_API_KEY` | Auth token for your MCP server. | Required if `NEXT_PUBLIC_USE_MOCK_CORAL=false`. |
| `OPENAI_API_KEY` | (Optional) Used for advanced LLM reasoning. | Obtain at [platform.openai.com](https://platform.openai.com). |
| `GROQ_API_KEY` | (Optional) Used for fast, cheap LLM reasoning. | Obtain at [console.groq.com](https://console.groq.com). |
| `ANTHROPIC_API_KEY` | (Optional) Used for Claude reasoning. | Obtain at [console.anthropic.com](https://console.anthropic.com). |

## Keeping Keys Safe
- `docs/API_KEYS.md` and `.env.example` should only ever contain placeholder values.
- Your `.env.local` file is explicitly ignored in `.gitignore`.
- If a secret is leaked, immediately roll the key in the respective provider dashboard.

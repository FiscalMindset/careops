# PR: Care Timeline UI

## Summary
Updated the Care Timeline page to use the real `CoralClient` abstraction and the `TIMELINE_QUERY` SQL instead of hardcoded mock logic. This page now visualizes the cross-source chronology of the patient's healthcare events.

## Files Changed
- `app/timeline/page.tsx`: Rewritten to fetch data using `CoralClient` by executing `TIMELINE_QUERY` parameterized for `pat-001`. Data from 5 disparate specs is UNION-ed together and mapped to the UI.
- `src/components/ui.tsx`: (Existing) `TimelineEventCard` is used to render the mapped events with the clean healthcare visual style.

## Tests Run
- Visually verified the timeline on the dev server (assuming it is running). It successfully lists medications, symptoms, chats, labs, and pharmacy receipts chronologically.

## Coral Relevance
The timeline is generated by a single massive `UNION ALL` SQL query executed through the Coral layer. This perfectly demonstrates Coral's value prop: taking data scattered across 5 different domain schemas and pulling it into a single, cohesive timeline view with zero manual application-side sorting or merging required.

## Safety Notes
The timeline is strictly chronological visualization of facts (logged records). It makes no inferences about causality between events (e.g., it does not state a medication caused a symptom, only that it happened after).

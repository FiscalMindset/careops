# CareOps Agent Video Demo

This directory contains the video demo storyboard for the CareOps Agent hackathon submission.

## How to Record

1. Open `index.html` in a browser
2. Click "▶ Start Presentation" to auto-advance through scenes
3. Or scroll manually using the navigation dots
4. Screen record at 1920×1080, under 3 minutes

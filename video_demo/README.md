# CareOps Agent — Demo Video

Cinematic 8-scene demo video for CareOps Agent, built as part of the Coral Hackathon (Track 2).

## Structure

| Scene | Title | Duration |
|-------|-------|----------|
| 1 | Production Intro | 8-10 sec |
| 2 | The Real Problem | 18-22 sec |
| 3 | What CareOps Does | 18-22 sec |
| 4 | Tech Stack & Architecture | 25-30 sec |
| 5 | Real App Demo | 45-60 sec |
| 6 | Coral SQL Evidence | 20-25 sec |
| 7 | Safety Boundary | 12-15 sec |
| 8 | Ending / Build Proof | 12-15 sec |

## Usage

Open `index.html` in a browser or use OBS/screen recording to capture the full presentation.

- **Arrow Right / Space** — Next scene
- **Arrow Left** — Previous scene
- **R** — Restart to scene 1
- **Side dots** — Jump to any scene

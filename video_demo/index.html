Coral SQL Evidence

Every answer is explainable through queryable evidence

SQL Query
SELECT m.medicine_name, m.dose, m.frequency, s.symptom, s.severity, l.test_name, l.value, l.unit, d.message AS doctor_instruction, p.quantity AS refill_qty, a.appointment_date, a.status, n.note_text AS family_note FROM careops_medications.medications m LEFT JOIN careops_symptom_logs.symptom_logs s ON s.patient_id = m.patient_id LEFT JOIN careops_lab_reports.lab_reports l ON l.patient_id = m.patient_id LEFT JOIN careops_doctor_chats.doctor_chats d ON d.patient_id = m.patient_id LEFT JOIN careops_pharmacy_receipts.pharmacy_receipts p ON p.patient_id = m.patient_id LEFT JOIN careops_appointments.appointments a ON a.patient_id = m.patient_id LEFT JOIN careops_family_notes.family_notes n ON n.patient_id = m.patient_id WHERE m.patient_id = 'pat-001' ORDER BY m.start_date DESC;

Safety Boundary

⚠️ Not a medical device

  • ✗ Does not diagnose conditions
  • ✗ Does not prescribe medicine
  • ✗ Does not recommend medicine changes
  • ✓ Organizes existing care records
  • ✓ Prepares questions for a licensed doctor
  • ✓ All demo data is synthetic / mock

CareOps is a care-coordination tool. Always consult a licensed physician for medical decisions.

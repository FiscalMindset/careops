The Problem

Family care records are scattered across WhatsApp chats, pharmacy receipts, lab PDFs, doctor appointment cards, symptom notes, and prescription photos. There is no single view.

03

The Solution

CareOps Agent ingests 9 synthetic care sources via Coral, joins them with SQL, and generates a one-page doctor-visit packet — medicines, labs, instructions, refills, and missing records — in seconds.

Coral SQL Evidence

The agent queries Coral with a multi-table SQL join. Every evidence row is fully transparent and attributable.

SQL Query (auto-generated)
SELECT m.medicine_name, m.dose, m.frequency,
       s.symptom, s.symptom_date,
       l.test_name, l.value, l.unit,
       d.doctor_instruction, d.date AS instruction_date,
       r.refill_quantity, r.refill_date,
       CASE WHEN r.refill_quantity IS NOT NULL
            AND s.symptom IS NOT NULL
            AND l.test_name IS NOT NULL
       THEN 'high' ELSE 'medium' END AS confidence
FROM medications m
LEFT JOIN symptom_logs s ON m.patient_id = s.patient_id
LEFT JOIN lab_reports l ON m.patient_id = l.patient_id
LEFT JOIN doctor_chats d ON m.patient_id = d.patient_id
LEFT JOIN pharmacy_receipts r ON m.medicine_name = r.medicine
WHERE m.patient_id = 'pat-001';

Safety Boundary

CareOps Agent is a care-coordination tool, not a medical device. It organizes existing records — it never diagnoses, recommends, or interprets.

SCREENSHOT: Safety notice banner rendered at the top of dashboard and packet pages
